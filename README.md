# CV en ligne

CV en ligne réalisé en HTML et CSS (devoir bilan CEF).

## Structure

- `index.html` : la page du CV
- `assets/css/style.css` : la mise en forme
- `assets/fonts/` : la police Raleway (importée avec `@font-face`)
- `assets/img/` : photo de profil, favicon et icônes
- `validation/` : captures des validations W3C

Icônes : Font Awesome Free (licence CC BY 4.0). Polices : Lato et Raleway (licence SIL Open Font License).

## Validation W3C

Le code a été validé sans erreur ni avertissement avec le validateur du W3C (validator.w3.org) :

- `index.html` : voir [validation/validation-html.png](validation/validation-html.png)
- `assets/css/style.css` : voir [validation/validation-css.png](validation/validation-css.png)
